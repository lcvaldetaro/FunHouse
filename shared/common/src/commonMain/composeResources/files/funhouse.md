# Fun House Escape

            

### Version 2.0 - Find the Exit!

        
        
        

---

        

You find yourself trapped inside a strange and mysterious Fun House. Move through the hall of mirrors, climb ladders, dig up hidden areas, unlock secret passages using keys, and complete your assigned goal!

        

**💡 Tip:** Some objects have unexpected, undesirable, or magical effects. If you get stuck, try using different action verbs or manipulating objects in different rooms.

        

---

        

## Game Commands

Interact with the world using simple 1 or 2 word commands:

### Movement
Move between locations using cardinal directions:
* **north** (**n**), **south** (**s**), **east** (**e**), **west** (**w**)
* **northeast** (**ne**), **northwest** (**nw**), **southeast** (**se**), **southwest** (**sw**)
* **up**, **down**, **in**, **out**, **inside**, **outside**, **enter**, **move**, **go**

### Observation
* **look** (or **?**) - Re-describe the current room, showing exits and visible items.
* **where** - Find out where other players are.

### Item Management
* **get** / **take** / **grab** *<item>* - Pick up an item.
* **drop** / **leave** *<item>* - Drop an item in the room.

### Interactions
* **open** / **unlock** *<door>* - Open a closed door or container.
* **close** *<door>* - Close a container.
* **start** *<console>* - Start/activate machinery.
* **dig** - Search the ground (requires a shovel).
* **read** *<object>* - Read signs, instructions, or plaques.
* **ask** *<character>* - Talk to characters you encounter.

### System
* **inventory** (or **i**) - View the list of items in your carrying slots.
* **score** - Show your current achievements and points.
* **goal** (or **goals**) - Display your active mission goal.
* **players** - List all the current players in the game.
* **save** - Save your progress.
* **restore** / **load** - Reload your last saved game state.
* **newhandle** *<nickname>* - Change player name and randomize character roles.
* **help** - Display this command helper window.
* **quit** - Exit the game.
